# EmyBrand

Sitio de presentación estático para GitHub Pages. Usa HTML, CSS y JavaScript nativos; no requiere Node.js, Next.js ni Vercel.

## Desarrollo local

Abre `index.html` en el navegador o ejecuta un servidor estático desde esta carpeta, por ejemplo:

```sh
python3 -m http.server 8000
```

Luego visita `http://localhost:8000`.

## Publicación

El flujo de GitHub Actions en `.github/workflows/pages.yml` publica el contenido de la raíz al hacer push a `main`. En la configuración del repositorio, GitHub Pages debe usar **GitHub Actions** como fuente. La dirección de proyecto esperada es `https://juliocastro0357-dot.github.io/EmyBrand/`.
